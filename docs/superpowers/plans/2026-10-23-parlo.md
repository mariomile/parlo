# Parlo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu-bar macOS dictation app: hold Fn, speak, release, and on-device transcribed (optionally LLM-cleaned) text is pasted into the focused field of any app.

**Architecture:** A local SwiftPM package `ParloKit` holds all logic. `ParloCore` is pure Swift (models, settings, prompt building, text transforms, pipelines, model catalog/manager, LLM client) and is unit-tested with `swift test`. `ParloEngines` wraps FluidAudio, WhisperKit and Apple SpeechAnalyzer behind the `Transcriber` and `ModelInstaller` protocols. The `App/` target (XcodeGen) holds only system I/O and SwiftUI: event tap, audio capture, paste, HUD, menu, settings, onboarding.

**Tech Stack:** Swift 6.4, SwiftUI, macOS 26+, XcodeGen, Swift Testing, FluidAudio 0.17.7, WhisperKit (argmax-oss-swift) 1.1.1, Apple Speech framework.

**Spec:** `docs/superpowers/specs/2026-10-23-parlo-design.md`

**Status:** implemented. Later work refactored parts of the file map below: `DictationPipeline` and `CommandPipeline` became `TranscriptionJob`, `RecordingGuard` lives in `Transcriber.swift`, `KeyPoster`, `TextInserter`, `SelectionReader`, `FrontmostApp` and `Permissions` share `App/SystemIO.swift`, and `ParloEngines` gained Qwen3-ASR, Silero VAD, Apple Intelligence and the on-device cleanup model. The task text below is the original plan.

## Global Constraints

- Minimum macOS 26.0. Swift language mode 6. Not sandboxed. Hardened runtime with `com.apple.security.device.audio-input`.
- Bundle ID `com.mariomiletta.parlo`. `LSUIElement = YES`. Ad-hoc signing in `project.yml` (`CODE_SIGN_IDENTITY = "-"`); `scripts/build.sh` re-signs (Sparkle's nested helpers first) with a local self-signed certificate so macOS keeps permissions across rebuilds.
- Dependencies pinned exactly in `ParloKit/Package.swift`: FluidAudio `0.17.7`, argmax-oss-swift `1.1.1`, plus mlx-audio-swift, mlx-swift-lm, swift-huggingface and swift-transformers, added with Qwen3-ASR and the on-device cleanup model.
- `Parlo.xcodeproj` is generated by `xcodegen` and gitignored.
- App UI copy in English.
- Settings JSON at `~/Library/Application Support/Parlo/settings.json`. API key only in Keychain (service `com.mariomiletta.parlo`, account `llm-api-key`).
- FluidAudio models live in FluidAudio's default cache `~/Library/Application Support/FluidAudio/Models` (shared with FluidVoice). WhisperKit models in `~/Library/Application Support/Parlo/Models/whisperkit`.
- Recordings shorter than 0.3 s are discarded. LLM cleanup timeout 5 s, command mode 15 s.
- An LLM failure never loses a dictation: paste the uncleaned text and warn in the HUD.

## Shared interfaces (every task's contract)

```swift
// ParloCore
public enum Style: String, Codable, CaseIterable, Sendable { case formal, casual, veryCasual, technical, neutral }
public struct DictionaryEntry: Codable, Equatable, Identifiable, Sendable { public var id: UUID; public var term: String; public var heardAs: [String] }
public struct Snippet: Codable, Equatable, Identifiable, Sendable { public var id: UUID; public var trigger: String; public var text: String }
public struct LLMSettings: Codable, Equatable, Sendable { public var enabled: Bool; public var baseURL: String; public var model: String }
public struct AppSettings: Codable, Equatable, Sendable {
  public var activeModelID: ModelID; public var languageCode: String?; public var llm: LLMSettings
  public var styleOverrides: [String: Style]; public var dictionary: [DictionaryEntry]; public var snippets: [Snippet]
  public var hasCompletedOnboarding: Bool
}
public protocol Transcriber: Sendable { func transcribe(_ samples: [Float], languageCode: String?) async throws -> String }
public protocol ChatCompleting: Sendable { func complete(system: String, user: String, timeout: TimeInterval) async throws -> String }
public protocol ModelInstaller: Sendable {
  func isInstalled(_ id: ModelID) async -> Bool
  func install(_ id: ModelID, progress: @escaping @Sendable (Double) -> Void) async throws
  func uninstall(_ id: ModelID) async throws
  func makeTranscriber(_ id: ModelID) async throws -> any Transcriber
}
```

## Tasks

Each task: write the failing Swift Testing test, run `swift test --filter <Suite>` (from `ParloKit/`) and see it fail, implement, see it pass, commit.

### Task 1: Scaffold
Files: `ParloKit/Package.swift`, `project.yml`, `.gitignore`, `scripts/run.sh`, `App/ParloApp.swift` (empty MenuBarExtra), `App/Info.plist`, `App/Parlo.entitlements`.
- [x] Package resolves and `swift build` succeeds with FluidAudio and WhisperKit.
- [x] `xcodegen generate && xcodebuild -scheme Parlo build` succeeds; the app shows a menu bar icon.
- [x] Commit `Scaffold Parlo package and app target`.

### Task 2: Settings + SettingsStore
Tests (`SettingsStoreTests`):
- missing file -> `AppSettings.default` (activeModelID `.appleSpeech`, LLM disabled, Groq base URL `https://api.groq.com/openai/v1`, model `llama-3.3-70b-versatile`).
- save then load round-trips every field.
- corrupt file -> defaults returned and the file is renamed to `settings.corrupt-<unix ts>.json`.
- decoding a file missing newer keys still works (custom `init(from:)` with `decodeIfPresent` defaults).

### Task 3: StyleResolver
`StyleResolver.style(for bundleID: String?, overrides: [String: Style]) -> Style`. Tests: override beats default; `com.apple.mail` formal; `com.tinyspeck.slackmacgap` casual; `com.apple.MobileSMS` veryCasual; `com.todesktop.230313mzl4w4u92` (Cursor) technical; unknown and nil -> neutral.

### Task 4: DictionaryReplacer
`DictionaryReplacer.apply(_ text: String, entries: [DictionaryEntry]) -> String`. Tests: case-insensitive whole-word ("cloud code" -> "Claude Code"); no replacement inside another word; longest phrase first; regex metacharacters in `heardAs` are escaped; accented letters count as word characters.

### Task 5: SnippetCodec
`SnippetCodec.encode(_ text: String, snippets: [Snippet]) -> (text: String, used: [String: Snippet])`, `decode(_ text: String, used:) -> String`, `allTokensPresent(_ text: String, used:) -> Bool`. Token format `⟦S1⟧`. Tests: standalone trigger; inline trigger inside a sentence; case and punctuation between trigger words ignored ("My, address." matches "my address"); decode restores the saved text; missing token detected.

### Task 6: PromptBuilder
`PromptBuilder.cleanupSystemPrompt(style: Style, terms: [String], hasPlaceholders: Bool) -> String`, `commandSystemPrompt() -> String`, `commandUserMessage(instruction: String, selection: String?) -> String`. Tests: style line present per style; terms listed only when non-empty; placeholder rule only when `hasPlaceholders`; command user message wraps selection in `<<< >>>` and says generation when no selection.

### Task 7: LLMClient + KeychainStore
`LLMClient(settings: LLMSettings, apiKey: String?, session: URLSession)` implements `ChatCompleting`. POST `{baseURL}/chat/completions`, `temperature: 0`, Bearer header only when key set. Errors `LLMError.http(Int, String)`, `.emptyResponse`. Tests with a `URLProtocol` stub: request URL/body/headers; success parses `choices[0].message.content` trimmed; 401 -> `.http(401, …)`; empty content -> `.emptyResponse`.
`KeychainStore.read() -> String?`, `save(String?)` (nil deletes). Smoke-tested in the app, not in unit tests.

### Task 8: Pipelines, RecordingGuard, HotkeyStateMachine
- `RecordingGuard.isLongEnough(sampleCount: Int, sampleRate: Double = 16_000) -> Bool` (>= 0.3 s).
- `DictationPipeline(transcriber:, llm: ChatCompleting?, settings:)`, `run(samples:, bundleID:) async throws -> DictationOutcome` with `.discarded`, `.empty`, `.inserted(text: String, cleanupError: String?)`.
  Tests with fakes: short audio discarded; whitespace transcript -> empty; no LLM -> dictionary + snippets applied; LLM receives style + placeholders and its output is expanded; LLM throws -> uncleaned text + cleanupError; LLM drops a token -> uncleaned text + cleanupError.
- `CommandPipeline(transcriber:, llm: ChatCompleting?, languageCode:)`, `run(samples:, selection: String?) async throws -> CommandOutcome` with `.discarded`, `.empty`, `.result(String)`; throws `CommandError.llmNotConfigured`. Tests: nil LLM throws; selection forwarded; empty instruction -> empty.
- `HotkeyStateMachine.handle(fn: Bool, ctrl: Bool) -> HotkeyAction?` with `.startDictation`, `.startCommand`, `.stop`. Mode decided at Fn press (Ctrl held -> command). Releasing Ctrl mid-command doesn't stop; Fn release stops. Tests cover each transition and repeated flag events.

### Task 9: ModelCatalog + ModelManager
- `ModelID` cases: `appleSpeech, parakeetV3, parakeetUltra, parakeetRedux, parakeetV2, cohereTranscribe, nemotronMultilingual, whisperTiny, whisperBase, whisperSmall, whisperLargeV3Turbo`. `ModelInfo` has `displayName, engine, approxSizeMB, languagesNote, note, requiresExplicitLanguage, needsDownload`.
- `@MainActor @Observable ModelManager(installer:, settingsStore:)`: `states: [ModelID: ModelState]` (`.notInstalled, .downloading(Double), .installed, .failed(String)`), `refresh()`, `download(_:)`, `cancel(_:)`, `delete(_:)`, `select(_:)`, `transcriber() async throws -> Transcriber` (cached per active ID).
  Tests with a fake installer: download goes downloading -> installed; failure -> failed; cancel -> notInstalled and installer task cancelled; delete active -> active becomes appleSpeech; select persists; transcriber cached until active changes.

### Task 10-13: Engine backends (ParloEngines)
`EngineInstaller: ModelInstaller` dispatches by `ModelInfo.engine`.
- Parakeet: `AsrModels.download(version:progressHandler:)`, `AsrModels.modelsExist(at: AsrModels.defaultCacheDirectory(for:), version:)`, `AsrModels.load(from:version:)`, `AsrManager.loadModels`, `transcribe(_:decoderState:language:)`.
- Cohere: `ModelHub.download(.cohereTranscribeCoreml, to:progressHandler:)`, `CoherePipeline.loadModels`, `transcribeLong(audio:models:language:)`. Language required, else `TranscriptionError.languageRequired`.
- Nemotron: `StreamingNemotronMultilingualAsrManager.downloadVariant`, `loadModels(from:)`, `reset`, `setLanguage`, `process(samples:)`, `finish()`.
- WhisperKit: `WhisperKit.download(variant:downloadBase:progressCallback:)`, `WhisperKit(WhisperKitConfig(modelFolder:…))`, `transcribe(audioArray:decodeOptions:)`.
- Apple Speech: `SpeechTranscriber`, `AssetInventory.assetInstallationRequest(supporting:)`, `SpeechAnalyzer` fed one 16 kHz buffer converted to `bestAvailableAudioFormat`.
- Integration test per engine (`PARLO_INTEGRATION=1`): `say -v Alice` Italian and `say -v Samantha` English to WAV, load 16 kHz samples, transcribe, assert key words. Skipped when not installed.

### Task 14-18: App layer
- `HotkeyMonitor` (CGEvent tap, `.listenOnly`, re-enable on timeout), `AudioRecorder` (AVAudioEngine + AVAudioConverter to 16 kHz mono, RMS level), `KeyPoster`, `TextInserter` (restore after 250 ms), `SelectionReader` (poll changeCount up to 300 ms), `FrontmostApp`, `Permissions`.
- `HUD`: recording waveform, processing spinner, message auto-hide after 2.5 s. Non-activating NSPanel, bottom center.
- `AppController`: press -> check permissions, model ready, capture app/selection, start recording, HUD; release -> stop, run pipeline, paste or HUD error; keeps `lastDictation`.
- Menu: status, active model, Copy last dictation, Settings…, Quit.
- Settings tabs: General (hotkeys, language picker, permissions), Models (catalog rows with Download/Cancel/Delete/Use, progress), AI (toggle, provider presets Groq/OpenAI/OpenRouter/Ollama, base URL, model, key, Test button), Styles (table of bundle ID -> style with app picker from running apps), Dictionary, Snippets.
- Onboarding window: Microphone, Accessibility, Input Monitoring rows polled every 1 s, Fn-key instruction with a button to Keyboard settings, Parakeet v3 download.
